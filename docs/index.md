# Build with zcash.js

The developer guide for zcash.js, hosted on GitHub Pages: practical TypeScript examples for chain queries, local wallets, receiving, sending, signing, and payment recovery.

Start with [installation and a first request](api/installation.md), then follow the [developer guide](api/README.md). For the complete wallet journey, read the [walkthrough](api/walkthrough.md). The [API reference](api/reference.md) maps the implemented exports to examples.

The SDK is an experimental release candidate; registry publication remains owner-controlled. It includes the wallet runtime, workers, and local Sapling proving assets. Wallet execution loads the bundled engine automatically, and proving assets load only when needed. Applications supply endpoints and storage. See [wallet setup](api/wallet-runtime.md) and [platform limits](api/platforms.md) for current requirements and qualification limits.

See [Maintain and publish](api/gitbook.md) to edit, preview, and deploy this VitePress guide to GitHub Pages. Planning and research are retained separately as historical context; use the developer guide and source exports for current usage.
