# Build with zcash.js

A practical TypeScript guide to chain queries, local wallets, receiving, sending, signing, and payment recovery.

Start with [installation and a first request](api/installation.md), then follow the [developer guide](api/README.md). For the complete wallet journey, read the [walkthrough](api/walkthrough.md). The [API reference](api/reference.md) maps the implemented exports to examples.

The SDK is experimental and privately packaged. Wallet execution requires a compatible runtime supplied by your application. The guide explains the setup and current limits without assuming a public npm release or hosted backend.

The same chapters are ready for [GitBook Git Sync](api/gitbook.md). Planning and research are retained separately as historical context; use the developer guide and source exports for current usage.
